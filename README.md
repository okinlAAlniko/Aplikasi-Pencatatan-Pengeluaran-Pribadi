# Aplikasi-Pencatatan-Pengeluaran-Pribadi
Aplikasi ini dibuat untuk mencatat pengeluaran sehari-hari, seperti makan, transportasi, dan hiburan kita. Topik ini juga cocok dengan konsep CRUD dan Array of Objects, sehingga saya dapat menerapkan seluruh materi Backend Basic, seperti modularisasi, arrow function, array methods, dan validasi, dalam satu program yang bermanfaat.
